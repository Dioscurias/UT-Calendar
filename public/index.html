UT Class Schedule → Google Calendar

Screenshot your class list, drop it below, verify the extracted classes, and download a calendar file for the whole semester. Runs entirely in your browser — no server, no account, no AI involved.

1 Add a screenshot

Log in to utdirect.utexas.edu, open your class list / schedule page, and take a screenshot (Mac: ⌘⇧4 then drag, or ⌘⌃⇧4 to copy straight to your clipboard). Make sure your whole schedule is visible before capturing. Text is read with OCR (optical character recognition), which struggles with gridded/bordered tables — it does best on courses with a single meeting pattern; a course with two separate meeting times (e.g. lecture + discussion) may come through with a placeholder title you'll need to fill in by hand, even though its days/times/rooms are still correct. If a screenshot doesn't parse well, the "paste text instead" option below is more reliable since it reads UT's actual data, not pixels.

4 Generate

Browsers won't let a page silently pick a file and import it into another site for you — that's a deliberate security boundary, not something this tool can route around. The closest real equivalent: Google Calendar's own "add event" link, pre-filled and opened in a new tab, where you just click Save.

Import into Google Calendar

  1. Open calendar.google.com → Settings → Import & export.
  2. Under "Import", click Select file from your computer and choose the .ics file you just downloaded.
  3. Pick which calendar to add the classes to (consider creating a new one called "Fall 2026 Classes" first, so it's easy to remove later).
  4. Click Import.
  5. To give each class its own color: .ics import doesn't carry colors, so Google Calendar gives every imported event the destination calendar's color by default. Click any occurrence of a class, choose "All events" when it asks, and pick a color — that recolors the whole recurring series in one go. Repeat once per class (not per occurrence).
